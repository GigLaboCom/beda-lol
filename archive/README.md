# Яхта «Беда» — архив рубрики

Рубрика персонального бренда о том, как люди строят пет-проекты, «плывя на яхте Беда», и не вкладываются в маркетинг. Центральный каламбур: **ПОБЕДА = ПО + БЕДА**, где «ПО» — и приставка, и «программное обеспечение». Софт есть, а без продвижения от «победы» остаётся «беда».

В архиве — рабочая страница сайта рубрики, макет сайта с холста, две three.js-сцены (яхта и стенд анимации букв), техническая документация ко всему этому и детальное описание интерактивных тактик.

## Что дальше

Прототипы из этого архива становятся основой боевого проекта `beda.giglabo.com` в публичном монорепо `beda-giglabo`: Astro + Rust API + Supabase (Postgres и авторизация), один VPS для сайта и API, CI/CD на GitHub Actions. Всё расписано в `docs/07-spec-beda-giglabo.md`; содержимое архива в монорепо переезжает в `archive/` и `docs/`.

Чтобы начать делать руками Claude Code — открой `claude-code/BOOTSTRAP.md`: там шаги от пустого репозитория до первого `/step 00`.

## Как запустить

Все HTML-файлы в `site/` и `src/` самодостаточны: открыть в браузере двойным щелчком. Сборка, сервер и npm не требуются.

- `site/yacht-beda-site.html` — работает и без интернета, только шрифты подгружаются с Google Fonts (без них включатся системные). Прогресс трекера хранится в браузере.
- `src/*.html` — нужен интернет: three.js r128 подгружается с `cdnjs.cloudflare.com`.
- `design/canvas/*.dc.html` — это файлы холста Design, они открываются только внутри холста. Для просмотра в браузере — `site/`.

Если нужен офлайн: скачать `three.min.js` r128 рядом с файлами и заменить `src` в теге `<script>` на локальный путь.

## Статус компонентов

| Компонент | Состояние |
|---|---|
| Сайт: главная | Готово, все разделы из макета, адаптив до телефона |
| Сайт: «Осмотр судна» | Работает: 12 вопросов, буквы падают по ответам, класс судна, три действия, копирование текста для шеринга |
| Сайт: «Как назовёшь» | Работает с маленьким словарём (~60 слов); на многих названиях слово не складывается |
| Сайт: «Моя яхта» | Работает: гвозди, анимация, сохранение в браузере; ржавчины и напоминаний нет |
| Сайт: калькулятор, шторм, реестр, треугольник | Карточки «скоро», механик нет |
| Картинка для шеринга | Есть в макете, на сайте не генерируется |
| Макет на холсте | 6 экранов; у висящей «О» в трекере неверное направление поворота |
| Корпус, симметрия, транец яхты | Готово. Моделируется правый борт, левый — зеркало |
| Рангоут, паруса, такелаж | Готово. Паруса на одном галсе, есть режим «плоские» |
| Надпись на транце в 3D-сцене | Работает **старая** механика: буква падает сразу, без креплений |
| Анимация «П» и «О» на стенде | Готово: дрожь → 4 затухающих качания → падение; «О» опрокидывается на клёпке |
| Анимации Б, Е, Д, А на стенде | Не сделаны; риг есть, крепёж по умолчанию угловой |
| Перенос анимации в 3D-сцену | Не сделан; план в `docs/03-integration-plan.md` |

## Оговорка по правам

Модель яхты, экипаж (его нет) и визуальный стиль — свои, не из мультфильма. Слово «БЕДА» на транце и шутка с отпадающими буквами — общеупотребимый гэг, персонажи и узнаваемые образы оригинала в рубрике не используются и использоваться не должны.
