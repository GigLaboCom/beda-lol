# 01 — «Осмотр судна»

**Диагностический квиз: 12 вопросов, по два на каждую букву ПОБЕДА. Результат — твоя табличка на транце с отвалившимися и повисшими буквами.**

## Зачем

Вход в рубрику. Одна сессия на 60–90 секунд, результат, который смешно и немного больно показать другим. Даёт трафик, шеринг и — побочно — данные о том, какие столпы аудитория проваливает чаще всего. Эти данные сами по себе материал для постов.

## Механика

1. Человек видит свою яхту с целой надписью ПОБЕДА. Сверху: «Осмотр судна перед выходом в море. 12 вопросов, честно».
2. По одному вопросу на экран, ответы «да» / «нет» / «частично» (частично = 0,5).
3. Каждый вопрос привязан к букве. По мере ответов у буквы вылетают клёпки — прямо на глазах, анимацией из стенда (фаза `shudder` с одним гвоздём).
4. После последнего вопроса — подсчёт по каждой букве:

| Сумма по двум вопросам | Состояние буквы |
|---|---|
| 2 или 1,5 | прибита — остаётся на месте |
| 1 или 0,5 | висит на одном гвозде — анимация доходит до `swing` и застывает на равновесии |
| 0 | отваливается — полная анимация с падением |

5. Буквы отваливаются по очереди слева направо, с паузой 0,4–0,6 с. Камера — вид с кормы, крупно.
6. Экран результата: итоговая надпись (например, «__БЕ_А»), класс судна, три конкретных действия, кнопки «Поделиться», «Прибить буквы» (→ тактика 03), «Пройти заново».

## Вопросы (черновик)

| Буква | Вопрос 1 | Вопрос 2 |
|---|---|---|
| П | Можешь одной фразой сказать, для кого твой проект? | Знаешь, чем он лучше того, чем люди пользуются сейчас? |
| О | Говорил за последний месяц хотя бы с пятью потенциальными пользователями? | Кто-то, кроме друзей, пользовался проектом и дал обратную связь? |
| Б | Есть что-то бесплатное, что приводит людей само — статья, инструмент, шаблон? | Писал о проекте или его теме хоть раз за последний месяц? |
| Е | Есть страница, где за 10 секунд понятно, что это? | Можно ли на этой странице оставить почту или начать пользоваться? |
| Д | Есть канал, куда ты регулярно выходишь с проектом? | Знаешь, где конкретно собирается твоя аудитория? |
| А | Знаешь, сколько людей пришло за последнюю неделю? | Знаешь, откуда они пришли? |

Формулировки проверять на трёх-пяти знакомых разработчиках: вопросы должны быть узнаваемыми и слегка неудобными, но без двусмысленности.

## Классы судна

Итоговый «класс» — текстовая награда, её и шерят. Вычисляется из числа прибитых букв.

| Прибито | Надпись (пример) | Класс | Подпись |
|---|---|---|---|
| 6 | ПОБЕДА | Флагман | «Редкость. Покажи остальным, как это делается» |
| 4–5 | ПОБЕ_А, _ОБЕДА | Шхуна на ходу | «Одна-две клёпки — и выходишь в море» |
| 2–3 | __БЕДА | Классическая «Беда» | «ПО есть. Победы нет. Узнаёшь?» |
| 0–1 | ___Е__ | Корпус на стапеле | «Проект есть. Судна пока нет» |

Особый случай: отвалились ровно П и О, остальное держится — показать отдельный текст про каламбур, это самый смешной и самый расшариваемый исход.

## Экран результата — три действия

Для каждой отвалившейся буквы — одно действие на 15–30 минут. Показывать три для самых «слабых» букв.

| Буква | Действие |
|---|---|
| П | Напиши фразу: «Для [кого], кто [проблема], [проект] — это [что], в отличие от [альтернатива]» |
| О | Найди трёх человек, у которых эта проблема, и спроси, как они решают её сейчас. Не продавай |
| Б | Возьми самую полезную вещь, которую узнал, пока делал проект, и напиши об этом пост |
| Е | Сделай страницу из трёх блоков: что это, для кого, кнопка |
| Д | Выбери один канал и поставь в календарь выход туда раз в неделю |
| А | Подключи любую простую аналитику и посмотри цифры через неделю |

## Шеринг

- **Картинка.** Снимок сцены с кормы (с отвалившимися буквами на полке) + название класса + маленький адрес сайта. Формат 1200×630 для превью ссылок и 1080×1350 для ленты.
- **Текст для копирования.** «Прошёл осмотр судна: у меня __БЕДА. А у тебя?» + ссылка.
- **Ссылка с результатом.** `/osmotr?r=0.5-0-1-2-2-1` — параметры кодируют баллы по буквам. Открывший видит чужую яхту и кнопку «Проверить свою». Серверная OG-картинка по этим параметрам, чтобы превью в мессенджерах показывало именно результат.

## Использование в рубрике

- Пост-анонс: автор проходит осмотр сам и показывает свою табличку.
- Раз в месяц — сводка по всем прохождениям: «чаще всего у вас отваливается О: 71% не говорили ни с одним пользователем». Это готовый пост с данными.
- Разборы: «почему П отваливается первой» с примерами из анонимных ответов.

## Данные

Без регистрации. Сохраняется анонимно:

```
attempt { id, created_at, scores: [П,О,Б,Е,Д,А] (0..2 шагом 0.5), class, shared: bool, source (utm) }
```

Этого достаточно для сводок. Никаких имён и почт на этом шаге.

## Техническая реализация

- Сцена: яхта из `src/yacht-threejs.html`, камера зафиксирована на виде с кормы, орбита отключена, чтобы ничего не отвлекало.
- Движок букв из стенда с дополнением: состояние `hang` — остановить фазу `swing` на `θ = eq` без падения.
- Во время вопросов: вылет одного гвоздя за каждый ответ «нет» (тот, что не является осью).
- Финальная раскладка: очередь анимаций, по букве за раз.
- Снимок для шеринга: `renderer.preserveDrawingBuffer = true` только на экране результата, затем `toDataURL('image/png')`, наложение текста на 2D-канвасе.
- Мобильная производительность: на слабых устройствах отключить тени и понизить pixel ratio до 1.

## Метрики

| Метрика | Ориентир для проверки гипотезы |
|---|---|
| Начали → дошли до результата | если < 60%, квиз длинный или вопросы скучные |
| Дошли → поделились | главный показатель гэга |
| Результат → «Прибить буквы» | работает ли переход в тактику 03 |
| Распределение классов | если почти все «Флагманы» — вопросы слишком лёгкие |

Ориентиры — это пороги, при которых стоит что-то менять, а не прогнозы.

## Риски

- **Люди врут в свою пользу.** Это нормально — квиз развлекательный. Но если почти все проходят на «Флагмана», ужесточить формулировки: «за последний месяц» вместо «когда-нибудь».
- **Ощущение нравоучения.** Лечится текстами результатов и тем, что автор публично показывает свою плохую табличку первым.
- **Вес анимации.** Сцена тяжелее обычного квиза. Показывать вопросы сразу, а яхту догружать в фоне.

## MVP → расширения

**MVP:** 12 вопросов, статичная табличка с отвалившимися буквами (без 3D), картинка для шеринга, ссылка с параметрами.
**Шаг 2:** 3D-сцена и анимации.
**Шаг 3:** серверные OG-картинки, сводная статистика, переход в трекер 03 с переносом баллов.
**Позже:** версии вопросов для разных типов проектов (open source, SaaS, мобильное приложение).

## Трудоёмкость

MVP — 2–4 дня. С 3D-анимацией и серверными превью — ещё 3–5 дней. Самая непредсказуемая часть — тексты вопросов и результатов: их придётся переписать несколько раз после первых реальных прохождений.

## Связи

→ **03** получает баллы как стартовое состояние. → **05** можно предложить как «а теперь посчитай, сколько воды в трюме». ← **02** может вести сюда как «проверь не название, а судно».
