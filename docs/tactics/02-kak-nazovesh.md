# 02 — «Как назовёшь»

**Вводишь название своего проекта — сайт показывает, что от него останется, если отвалится пара букв.**

## Зачем

Чистая виральная игрушка. Нулевой порог входа (одно поле ввода), мгновенный результат, смешной и персональный. Хорошо работает в комментариях к постам: люди вбивают названия своих и чужих проектов и делятся тем, что вышло. Даёт охват и узнаваемость механики «отпадающих букв» — после этого остальные тактики объяснять не надо.

## Механика

1. Поле «Как называется твой проект?», кнопка «Спустить на воду».
2. Название появляется на транце яхты (движок букв, раскладка по ширине глифов — работает для любой длины в пределах транца).
3. Алгоритм ищет, какие 1–3 буквы можно убрать, чтобы получилось настоящее слово — желательно смешное или зловещее.
4. Эти буквы отваливаются анимацией. Остаётся новое «название».
5. Подпись-вердикт: короткая шутка о том, как поплывёт судно с таким именем.
6. Кнопки: «Поделиться», «Другое название», «А теперь осмотр судна» (→ 01).

## Алгоритм

### Базовый поиск

Для названия длины `n` перебрать все способы убрать `k = 1…3` букв с сохранением порядка оставшихся. Это `C(n,1) + C(n,2) + C(n,3)` вариантов — для 12 букв около 300, мгновенно.

Каждый вариант проверить по словарю. Из найденных выбрать лучший по приоритету:

1. слово из курируемого «смешного» списка (беда, дыра, течь, рифы, мель, крах, ноль, баг, лень…);
2. любое существительное из общего словаря;
3. при равенстве — меньше убранных букв, затем длиннее результат.

### Словари

- Русский: список словоформ из открытого морфологического словаря (например, на базе OpenCorpora) или словаря Hunspell. Оставить только существительные в именительном падеже — иначе будет много мусора.
- Английский: частотный список (названия проектов часто латиницей).
- Курируемый список «смешных» слов — вручную, 200–500 штук, на обоих языках. От него зависит, насколько игрушка смешная, и это самая ценная часть работы.

Словари грузить на клиент не нужно целиком: отфильтровать по длине и отдавать с сервера только кандидатов, либо держать в браузере сжатый набор на 1–3 МБ.

### Когда ничего не нашлось

Для случайных названий (особенно латиницей и с цифрами) слово находится далеко не всегда. Честно: доля «попаданий» заранее неизвестна, её придётся измерить. Фолбэки по порядку:

1. **Каламбурный режим.** Если название начинается с «По…», «Про…», «Pro…» — отвалить приставку и обыграть.
2. **Отвалить первые две буквы** в любом случае, как у ПОБЕДЫ, и сделать шутку из бессмысленного остатка: «Судно „ектор“. Звучит как диагноз».
3. **Опционально — языковая модель** генерирует вердикт для любого остатка. Дороже и медленнее, зато всегда смешно. Если использовать, кешировать по названию.

## Вердикты

Шаблоны по типу результата. Примеры:

- «Было: *{исходное}*. Стало: *{результат}*. Классический путь пет-проекта».
- «Две клёпки — и твой *{исходное}* уже *{результат}*. Маркетинг держится на меньшем, чем кажется».
- Для слов из курируемого списка — собственные шутки на каждое слово.

## Шеринг

- Картинка: транец крупно, отвалившиеся буквы на полке, подпись «Было / Стало».
- Ссылка `/nazvanie?n=...` показывает тот же результат и поле «Проверь своё».
- Для мессенджеров — OG-картинка с результатом.

## Использование в рубрике

- Пост: «Проверил названия десяти популярных инструментов — вот что осталось». Брать только те, где результат добрый: смеяться над своим и над абстракцией, а не над конкретными людьми.
- Челлендж в комментариях: «Вбейте название своего проекта и покажите, что вышло».
- Разбор: «Почему название — это тоже маркетинг», с переходом к букве **П**.

## Данные

Минимум: название, результат, время. Название может быть неопубликованным проектом — не показывать чужие названия публично без согласия. Для сводок — только агрегаты.

## Техническая реализация

- Клиент: поле ввода, яхта с транцем, движок букв. Нормализация ввода: убрать эмодзи и лишние пробелы, ограничить длину — если не помещается на транец, уменьшить высоту букв или предложить сократить.
- Смешанные алфавиты и цифры: глиф рисуется любой, снап крепёжа работает для любого символа. Пробел — пропуск на транце без литеры.
- Поиск: в браузере или на сервере; для словаря на 1–3 МБ проще на сервере.
- Анимация: буквы, которые убирает алгоритм, получают полный цикл падения; остальные неподвижны.

## Метрики

- Доля названий, для которых нашлось настоящее слово — ключевой показатель качества игрушки.
- Повторные вводы за сессию (люди играют?).
- Шеринг и переходы в 01.

## Риски

- **Неприличные результаты.** Перебор с удалением букв гарантированно находит обсценную лексику. Нужен стоп-лист, применяемый к результату до показа. Это обязательно, не опционально.
- **Обидные результаты для реальных брендов.** Если кто-то вбивает чужой продукт — это его выбор, но в собственных постах рубрики чужие продукты высмеивать не стоит.
- **Низкая доля попаданий** на латинице. Лечится фолбэками и курируемым списком.

## MVP → расширения

**MVP:** поиск по небольшому курируемому списку + фолбэк «первые две буквы», статичная табличка, шеринг ссылкой.
**Шаг 2:** полный словарь, 3D-транец, OG-картинки.
**Позже:** режим «переименуй»: предложить три альтернативных названия, у которых ничего не отваливается.

## Трудоёмкость

2–5 дней. Разброс из-за словарей и курируемого списка: техника простая, качество шуток — нет.

## Связи
