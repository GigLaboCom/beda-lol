# 07 — «Бермудский треугольник»

**Кладбище заброшенных пет-проектов. Каждый оставляет свою затонувшую яхту с эпитафией: что строил, почему бросил, чего не хватило. Любую яхту можно попробовать поднять со дна.**

## Зачем

Самая исповедальная тактика и, скорее всего, самая расшариваемая. Про брошенные проекты у каждого разработчика есть история, и рассказывать её в формате шутливой эпитафии гораздо легче, чем в формате «разбор ошибок». Для рубрики это честный материал о том, *почему* проекты тонут, — в собственных словах аудитории. И это единственная тактика, которая работает с прошлым, а не с будущим, поэтому она не требует от человека усилий, только истории.

## Механика

### Карточка затонувшего судна

| Поле | Пример | Обязательно |
|---|---|---|
| Название | «Трекер привычек №4» | да |
| Годы плавания | 2023–2024 | да |
| Что строил, одной фразой | «Приложение, которое напоминало пить воду. Себе» | да |
| Причина крушения (выбор + свободный текст) | «Сделал идеально, показал никому» | да |
| Какая буква отвалилась первой | П / О / Б / Е / Д / А | да |
| Эпитафия, до 140 символов | «Здесь покоится 40 000 строк кода. Пользователей — ноль. Тесты — зелёные» | да |
| Ссылка на код или скриншот | | нет |
| Анонимно | | переключатель |

### Причины крушения (варианты для выбора)

- Строил, никому не показывал
- Показал, никто не понял
- Понял, но не нужно
- Нужно, но не мне — и стало скучно
- Выгорел
- Появилась работа / жизнь
- Сделали конкуренты
- Другое

Выбор даёт статистику, свободный текст — материал для постов.

### Сцена

- Тёмная вода, сверху вниз — дно, на дне лежат яхты с разной степенью «затопления» (чем старше, тем глубже и больше водорослей / ржавчины на латуни).
- У каждой на транце — какие буквы отвалились первыми, по выбору автора.
- Камера медленно плывёт вдоль дна; клик по яхте поднимает карточку с эпитафией.
- Не надо делать мрачно. Тон — тёплая ностальгия: «мы все здесь кого-то оставили».

### Поднять со дна

Любой может нажать «Поднять»: это сигнал автору, что кто-то готов взять идею, продолжить или хотя бы попробовать. Если автор согласен — связь (через почту или ссылку). Если проект открытый — ссылка на форк. Поднятая яхта переходит в реестр (06) с пометкой «спасена из треугольника».

Честно: число реальных «подъёмов» будет маленьким. Но сама кнопка меняет интонацию с «кладбища» на «гавань ожидания», и редкие случаи подъёма — отличный материал для постов.

### Отправка из трекера

Яхта из трекера 03, которая 90 дней не получала гвоздей, получает мягкое предложение: «Судно давно не выходило в море. Вернуться или отправить в треугольник с эпитафией?» Оба варианта нормальные, и оба дают данные.

## Модерация

- Премодерация (эпитафии короткие, проверка быстрая).
- Стоп-лист, запрет на чужие проекты без согласия («затопить» можно только своё).
- Анонимность по умолчанию доступна, но модератор видит автора.

## Использование в рубрике

- «Эпитафия недели» — одна история, одна картинка. Короткий регулярный формат.
- Сводка: «37% наших кораблей затонули, потому что их никто не видел» — данные в поддержку тезиса рубрики.
- Длинные истории: с согласия — интервью с автором затонувшего проекта о том, что бы он сделал иначе.
- Своя эпитафия первой: у автора наверняка есть брошенные проекты, и первый пост должен быть о своём.

## Данные

```
wreck    { id, author_id?, anonymous, name, years, tagline, cause, cause_text, first_letter,
           epitaph(≤140), url?, status (pending|live|hidden), created_at }
raise    { wreck_id, user_id, message?, created_at, accepted? }
```

## Техническая реализация

- Сцена: те же яхты, но с опциями «затопления» — крен 20–60°, материал корпуса темнее, туман с синим оттенком, лучи света сверху (плоскости с аддитивным градиентом).
- Производительность: как в реестре — упрощённые модели для дальних, детальная только выбранная.
- Список-версия без 3D обязательна.
- Картинка для шеринга: затонувшая яхта + эпитафия крупно.

## Метрики

| Метрика | Что показывает |
|---|---|
| Новые эпитафии в неделю | работает ли формат исповеди |
| Доля анонимных | насколько людям неловко; если почти все анонимны — это нормально |
| Шеринг эпитафий | главный показатель охвата |
| Распределение причин | материал для рубрики |
| Нажатия «Поднять» | интерес к чужим идеям |
| Переходы из треугольника в осмотр 01 | «а моя текущая яхта не туда же?» |

## Риски

- **Грусть вместо смеха.** Тон задаётся первыми эпитафиями и шаблонами-подсказками. Засеять 10–15 своих и знакомых, смешных и тёплых.
- **Тяжёлые истории.** Выгорание — реальная причина, и иногда за ней стоит что-то серьёзное. Тексты интерфейса не должны над этим шутить; вариант «выгорел» просто есть в списке, без комментариев.
- **Чужие проекты.** Затапливать можно только своё — это правило в форме и в модерации.

## MVP → расширения

**MVP:** форма, премодерация, список карточек, картинка для шеринга каждой эпитафии.
**Шаг 2:** 3D-дно, «Поднять со дна».
**Шаг 3:** связь с трекером (предложение через 90 дней), статистика причин на странице.

## Трудоёмкость

MVP — около недели. 3D-сцена дна — ещё неделя. Тексты подсказок и первые эпитафии важнее кода и требуют времени отдельно.
