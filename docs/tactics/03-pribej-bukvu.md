# 03 — «Прибей букву обратно»

**Личный трекер: твоя яхта начинает с таблички БЕДА (или с результата осмотра), и каждое маркетинговое действие прибивает клёпку. Цель — собрать ПОБЕДУ.**

## Зачем

Хребет возврата. Единственная механика из списка, которая даёт человеку причину прийти через неделю: его яхта ждёт, буквы висят, и у каждой написано, какой гвоздь не хватает. Прогресс виден физически — буквы возвращаются на транец. Это же и практическая польза: трекер превращает абстрактное «надо заняться маркетингом» в конкретный список маленьких шагов.

## Механика

### Состояние яхты

У каждой буквы 4 гнезда под крепёж (как на стенде). Буква:

| Прибито гвоздей | Состояние |
|---|---|
| 0 | лежит на полке под транцем |
| 1 | висит на одном гвозде, покачивается |
| 2–3 | на месте, но с пустыми гнёздами |
| 4 | прибита намертво, латунь блестит |

### Действия

Каждой букве соответствует список действий. Выполненное действие = один гвоздь. Действия трёх уровней, чтобы и новичок, и опытный находили своё:

| Буква | Лёгкое (15–30 мин) | Среднее (1–3 ч) | Серьёзное (день+) |
|---|---|---|---|
| П | написать фразу позиционирования | переписать заголовок лендинга по ней | проверить фразу на пяти людях и переписать |
| О | написать одному пользователю | провести один созвон | пять интервью и выписать повторяющиеся проблемы |
| Б | пост о том, чему научился | открытый полезный инструмент или шаблон | серия из пяти материалов |
| Е | страница «что это и для кого» | форма сбора почт | лендинг с примерами и отзывами |
| Д | выбрать канал | три выхода в канал за две недели | месяц регулярных выходов |
| А | подключить счётчик | посмотреть источники за неделю | поставить одну цель и отслеживать её |

Действия — черновик. Их список и есть основной контент тактики, его стоит собирать вместе с аудиторией (кнопка «предложить действие»).

### Подтверждение

Честная система: человек сам отмечает выполненное. Опционально — ссылка на доказательство (пост, страница, скриншот цифр). Ссылка делает гвоздь «латунным» (визуальный бонус), без неё — «железным». Это мягко поощряет публичность без жёсткой проверки.

### Ржавчина

Чтобы трекер не превращался в разовый чеклист: столпы Д (дистрибуция) и О (общение) требуют регулярности. Если за 30 дней в этих буквах не было новых действий, один гвоздь «ржавеет» и выпадает. Буква начинает покачиваться. Это единственная механика, которая отнимает прогресс, и она должна быть очень заметно объяснена заранее, иначе будет восприниматься как наказание.

## Пользовательский путь

1. Вход: из результата «Осмотра» (баллы переносятся) или напрямую («начать с БЕДЫ»).
2. Создание яхты: название проекта, ссылка (необязательно). Вход через почту-ссылку или GitHub.
3. Главный экран: транец крупно, под ним шесть карточек букв с прогрессом и одним предложенным действием на каждую.
4. Выполнил → отметил → анимация «прибивания»: гвоздь входит в гнездо, буква поднимается на место, если это был первый гвоздь.
5. Раз в неделю — напоминание (почта или Telegram-бот): «Буква О висит на одном гвозде уже 12 дней. Вот действие на 20 минут».
6. Сборка ПОБЕДЫ целиком — отдельная сцена: яхта поднимает паруса и уходит с полки. Картинка для шеринга.

## Анимация прибивания

Обратная к стенду, её нужно сделать отдельно:

- буква поднимается с полки по дуге к своему месту (обратная траектория падения, но плавная);
- на гвозде 0 — короткий «удар»: смещение пивота на 3–5 мм к доске и отскок, звук опционально;
- последующие гвозди — только удар, без подъёма.

## Шеринг

- Картинка текущего состояния транца с подписью «Моя яхта сегодня: ПОБ_ДА. Осталась Е».
- Публичная страница яхты (по желанию), которую можно показать в соцсетях. Это же — запись в «Судовом реестре» (06).
- Достижения на полную сборку и на «ни одной ржавой клёпки за 90 дней».

## Использование в рубрике

- Автор ведёт свою яхту публично и показывает прогресс раз в неделю — самый естественный повторяющийся формат.
- Истории аудитории: «собрал ПОБЕДУ за 6 недель — что сработало» (с согласия).
- Сводки: какие действия отмечают чаще всего, какие буквы собирают последними.

## Данные

```
user     { id, auth (email | github), created_at, reminder_channel }
yacht    { id, user_id, project_name, project_url, public: bool, created_at }
action   { id, letter, level, title, description, author (system | user_id), approved }
nail     { id, yacht_id, letter, slot (0..3), action_id, proof_url?, nailed_at, rusted_at? }
```

Состояние буквы вычисляется из `nail`, не хранится отдельно. Ржавчина — фоновая задача раз в сутки.

## Техническая реализация

- Сцена и движок букв из `src/`, плюс анимация прибивания.
- Бэкенд: авторизация, хранилище, фоновая задача для ржавчины и напоминаний.
- Напоминания: почта или бот в Telegram. Бот — лучший вариант для аудитории, которая живёт в Telegram, и дешёвый в реализации.
- Нужен экран без 3D (список букв и действий) для слабых устройств и для быстрого отмечания.

## Метрики

| Метрика | Что показывает |
|---|---|
| Возврат на 7-й / 30-й день | работает ли основная механика |
| Среднее число гвоздей на 30-й день | реальный прогресс людей |
| Доля действий со ссылкой-доказательством | публичность, а значит и распространение |
| Доля собравших ПОБЕДУ | достижимость цели; если ~0 — действия слишком тяжёлые |
| Отписки от напоминаний после ржавчины | не воспринимается ли ржавчина как наказание |

## Риски

- **Геймификация ради галочек.** Люди отмечают действия, не делая их. Для личного трекера это их выбор; но публичные «латунные» гвозди требуют ссылки, и это сдерживает.
- **Ржавчина раздражает.** Сделать её отключаемой и дать «отпуск» (заморозить яхту на месяц).
- **Сложность.** Регистрация, бэкенд, напоминания — это уже продукт, а не игрушка. Если нет ресурса, начать без ржавчины и напоминаний.

## MVP → расширения

**MVP:** вход по почте, одна яхта, шесть букв, фиксированный список действий, отметка без доказательств, статичная картинка транца.
**Шаг 2:** 3D-сцена и анимация прибивания, ссылки-доказательства, публичная страница.
**Шаг 3:** напоминания, ржавчина, достижения.
**Позже:** несколько яхт на человека, предложенные аудиторией действия с модерацией.

## Трудоёмкость

MVP — около недели. Полная версия с напоминаниями и ржавчиной — 2 недели и больше. Главная неизвестная — список действий: он определит, будут ли люди возвращаться, и его придётся править по данным.

## Связи

← **01** даёт стартовое состояние. → **06** публичная яхта автоматически попадает в реестр. → **07** заброшенную на 90 дней яхту можно предложить «отправить в треугольник» с эпитафией — или получить напоминание вернуться. ↔ **04** бортовой журнал автора — это его собственный трекер плюс лог.
