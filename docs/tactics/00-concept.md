# 00 — Концепция рубрики и сайта

## Суть в одной фразе

Люди строят пет-проекты, «плывя на яхте Беда»: код пишется, а маркетинга нет, и от ПОБЕДЫ остаётся БЕДА. Сайт рубрики превращает эту самоиронию в интерактивы, которые хочется пройти, расшарить и к которым хочется вернуться.

## Центральный каламбур

**ПОБЕДА = ПО + БЕДА.**

«ПО» читается двояко: как приставка, которая делает из беды победу, и как «программное обеспечение». Отсюда весь нарратив: *ПО у тебя есть. Без всего остального это не победа.*

Второй слой — физический: буквы на транце держатся на гвоздях и клёпках. Каждое несделанное маркетинговое действие — выпавшая клёпка. Каждое сделанное — прибитая обратно. Это даёт механику, которую легко понять без объяснений: визуально видно, что держится, а что отвалилось.

## Словарь метафор

Единый словарь нужен, чтобы все тактики и посты говорили на одном языке и не противоречили друг другу.

| Метафора | Что означает |
|---|---|
| Яхта | пет-проект, продукт |
| Название на транце | то, чем проект стал бы при нормальном продвижении |
| Буквы П-О-Б-Е-Д-А | шесть столпов продвижения (см. акростих ниже) |
| Гвоздь / клёпка | конкретное действие, которое держит столп |
| Выпавшая буква | столп, которым автор не занимается |
| Отпечаток буквы | «здесь что-то было» — брошенное начинание, след намерения |
| Течь, вода в трюме | отток, тишина, время, потраченное без обратной связи |
| Крен | перекос между кодом и маркетингом |
| Гавань | сообщество, реестр проектов |
| Спасательный круг | конкретный совет от другого человека |
| Буксир | подписка на чужой проект, поддержка |
| Шторм | рынок, случайные события |
| Бермудский треугольник | место, где пропадают проекты |
| Бортовой журнал | публичный лог работы |

## Акростих ПОБЕДА — черновик столпов

Это набросок, а не догма: смысл в том, чтобы у каждой буквы было содержание, и тогда «отколоть П» означало бы что-то конкретное. Переформулируй под свой голос.

| Буква | Столп | Что значит «прибита» |
|---|---|---|
| **П** | Позиционирование | можешь одной фразой сказать, для кого проект и чем он лучше альтернативы |
| **О** | Общение с пользователями | за последний месяц говорил хотя бы с пятью реальными людьми из аудитории |
| **Б** | Бесплатная ценность | есть контент, инструмент или материал, который приводит людей без рекламы |
| **Е** | Единая точка входа | лендинг или страница, где понятно, что это, и можно оставить контакт |
| **Д** | Дистрибуция | есть хотя бы один канал, куда регулярно выходишь (соцсеть, сообщество, рассылка) |
| **А** | Аналитика | знаешь, сколько людей пришло, откуда и что они сделали |

Удачное совпадение: первыми отваливаются **П** и **О** — позиционирование и разговоры с людьми. Это как раз то, что разработчики пропускают чаще всего, и именно без них ПОБЕДА становится БЕДОЙ. Шутка и тезис рубрики совпадают — это стоит использовать в первом посте.

## Тон

- **Самоирония, а не поучение.** Автор сам на этой яхте. Каждая тактика должна читаться как «мы все тут», а не «вот что вы делаете неправильно».
- **Смешно, но с реальными цифрами.** Шутка — вход, польза — причина остаться. Калькулятор течи смешной, но в нём реальные часы.
- **Не стыдить.** Результат «у тебя отвалились все буквы» должен вызывать смех и узнавание, а не желание закрыть вкладку. В текстах результатов всегда есть «что с этим сделать за 15 минут».
- **Коротко.** Любой интерактив проходится меньше чем за 2 минуты, кроме «Шторма» (до 5).

## Визуальный язык

Взят из three.js-сцены: тёплое дерево, латунь, выгоревший холст, тёмный бревенчатый фон. Шрифт с засечками для заголовков и надписей на транце, моноширинный — для цифр и логов. Никаких персонажей и узнаваемых образов из мультфильма: яхта своя, экипажа нет, есть только сам автор и его аудитория.

## Как тактики складываются в воронку

```
Вход (одна сессия, шеринг)          Возврат (повод прийти снова)         Контент от аудитории
─────────────────────────           ────────────────────────────         ─────────────────────
01 Осмотр судна          ─────▶     03 Прибей букву обратно    ─────▶    06 Судовой реестр
02 Как назовёшь                     04 Бортовой журнал (автора)          07 Бермудский треугольник
05 Калькулятор течи                                                       
08 Шторм (глубокая сессия)
```

Результат «Осмотра» — это стартовое состояние трекера «Прибей букву». Трекер публикуется в «Реестр». Брошенный трекер можно отправить в «Треугольник». Одна модель данных, один движок букв, одна яхта.

## Приоритизация

Оценки грубые, это ориентиры для выбора, а не план. «Усилие» — для одного разработчика, знакомого со стеком, без учёта дизайна и текстов.

| Тактика | Усилие MVP | Шеринг | Возврат | Контент от людей | Риск модерации |
|---|---|---|---|---|---|
| 01 Осмотр судна | 2–4 дня | высокий | низкий | нет | нет |
| 02 Как назовёшь | 2–5 дней | высокий | низкий | нет | низкий |
| 03 Прибей букву | 1–2 недели | средний | **высокий** | косвенно | низкий |
| 04 Бортовой журнал | 3–6 дней | средний | для автора | нет | нет |
| 05 Калькулятор течи | 1–3 дня | средний | низкий | нет | нет |
| 06 Судовой реестр | 1,5–3 недели | средний | средний | **высокий** | **высокий** |
| 07 Бермудский треугольник | 1–2 недели | высокий | низкий | **высокий** | средний |
| 08 Шторм | 1–3 недели | средний | средний | нет | нет |

Предлагаемый порядок, если выбирать минимальную связку: **01 → 03 → 06 или 07**. Первое даёт трафик и материал для постов, второе — повод возвращаться, третье — бесконечный источник контента для рубрики. 04 можно делать параллельно для себя — это самый дешёвый способ показать, что автор сам на борту.

## Общая техническая база

- **Одна сцена, много режимов.** Яхта и движок букв (`src/`) переиспользуются во всех визуальных тактиках. Для каждой тактики — свой набор столпов, свой «FAIL / HANG / OK» на букву.
- **Три состояния буквы** вместо двух: `прибита` / `висит на одном гвозде` (пауза в фазе swing на равновесии) / `отвалилась`. Среднее состояние — это «начал, но не довёл», самое честное и самое узнаваемое.
- **Шеринг-картинка** — снимок canvas (`renderer.domElement.toDataURL()`) плюс подпись. Для превью в соцсетях — серверная генерация OG-картинки по параметрам результата.
- **Стек.** Статика + небольшой бэкенд для реестра и треугольника. Если сайт живёт рядом с другими инструментами на Next.js, это естественное место: страницы тактик — маршруты, three.js — клиентский компонент, API — route handlers.
- **Без обязательной регистрации** для 01, 02, 05, 08. Для 03, 06, 07 — вход по ссылке на почту или через GitHub (аудитория — разработчики, GitHub для них естественен и сразу даёт ссылку на проект).

## Метрики, общие для всех тактик

| Метрика | Зачем |
|---|---|
| Доля дошедших до результата | качество входа, длина интерактива |
| Доля шерящих результат | работает ли гэг |
| Переходы из результата в следующую тактику | работает ли воронка |
| Возвраты на 7-й и 30-й день (для 03, 06) | живёт ли механика возврата |
| Переходы из рубрики на сайт и обратно | связь сайта и постов |
| Число проектов в реестре / треугольнике | объём контента для рубрики |

Честная оговорка: «вовлечение» — размытая цель. Стоит заранее решить, что считается успехом: подписки, разговоры с людьми, заявки, упоминания. От этого зависит, какие из метрик главные.

## Права

Модель, стиль, тексты — свои. Слово «БЕДА» и гэг с отпадающими буквами — общеупотребимая шутка. Персонажей, их образов, цитат и песен мультфильма в рубрике не использовать — ни на сайте, ни в картинках для постов.
