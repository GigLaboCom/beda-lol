# docs/scratch — незакоммиченные черновики

Свалка для spec-driven-dev: черновики спеков, заметки, планы, промпты — всё,
что нужно держать рядом с кодом, но не в истории git.

- Всё в этой папке игнорируется git, **кроме** самого `README.md`.
- README трекается только чтобы папка существовала у всех после клона.
- Когда черновик созрел — переноси его в нормальное место (`docs/`, `docs/steps/`,
  `docs/adr/` и т.п.) и коммить уже там.

Ничего секретного (ключи, `.env`, дампы, персональные данные) сюда тоже не клади —
привычка важнее, чем то, что файл не в git.
