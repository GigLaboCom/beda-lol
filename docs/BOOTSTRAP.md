# Как запустить Claude Code на проекте

Этот набор превращает спецификацию `docs/07-spec-beda-giglabo.md` в пошаговую работу для Claude Code. Один шаг — одна сессия, после каждого шага прод или тесты в рабочем состоянии.

## Один раз, руками

1. Создай на GitHub пустой публичный репозиторий `beda-giglabo` (без README и лицензии) и склонируй его.
2. Распакуй этот архив внутрь репозитория в папку `_import/`:
   ```
   beda-giglabo/
   └── _import/yacht-beda/...
   ```
3. Скопируй набор для Claude Code на место:
   ```bash
   cp _import/yacht-beda/claude-code/CLAUDE.md .
   cp -r _import/yacht-beda/claude-code/.claude .
   mkdir -p docs && cp -r _import/yacht-beda/claude-code/steps docs/steps
   ```
4. Установи локально: Node LTS, pnpm (через `corepack enable`), Rust через `rustup` (нужную версию подтянет `rust-toolchain.toml`), `sqlx-cli`, `cargo-deny`, `watchexec`, Docker, [Task](https://taskfile.dev), Supabase CLI, `gh` (GitHub CLI, залогиненный).
5. Открой Claude Code в корне репозитория.

## Дальше — по шагам

```
/step 00        выполнить конкретный шаг
/next           выполнить следующий невыполненный шаг из PROGRESS.md
```

Claude Code сам читает `CLAUDE.md`, журнал `docs/steps/PROGRESS.md` и файл шага, делает работу, прогоняет проверки, делает коммит и записывает итог в журнал.

## Где нужен ты

Шаги, в которых есть пункты с пометкой **[HUMAN]**, Claude Code не может сделать сам: купить VPS, прописать DNS, завести секреты в GitHub, подключить Search Console. Он остановится, перечислит, что нужно сделать, и подождёт. После этого скажи ему «готово» — он проверит и закончит шаг.

## Рекомендации

- Один шаг — одна сессия. Между шагами — `/clear`, чтобы контекст не копился.
- Перед шагом смотри его файл глазами: если что-то хочешь сделать иначе — поправь файл шага, а не объясняй в чате.
- Если шаг пошёл не туда — `git reset --hard` к последнему коммиту и перезапуск шага дешевле, чем исправление на ходу.
- Шаги после S14 описаны в `docs/steps/ROADMAP.md` одним абзацем. Перед началом этапа попроси: «разверни S15 из ROADMAP в полноценный файл шага по шаблону из steps/README.md».
